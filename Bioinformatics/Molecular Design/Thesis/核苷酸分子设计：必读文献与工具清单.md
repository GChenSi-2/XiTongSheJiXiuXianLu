# 核苷酸分子设计：必读文献与工具清单

本清单按"理论→算法→工具→前沿"四层组织，每篇都注明为什么重要、和你出题的关系。
精读 vs. 浏览的标记：⭐⭐⭐ 必须精读 / ⭐⭐ 通读 / ⭐ 知道存在即可。

## Layer 1：基础理论与综述（先读这一层，建立坐标系）

### A. mRNA疫苗设计总览（最权威的一篇综述）

**⭐⭐⭐ Jin et al. 2024, J Biol Chem**
"mRNA vaccine sequence and structure design and optimization: Advances and challenges"
DOI: 10.1016/j.jbc.2024.108015

为什么必读：这是2024年最系统的mRNA设计综述，覆盖序列设计、二级结构优化、
机器学习方法、面临的挑战。一篇读完你就有了完整知识图谱。直接对应你
Portfolio里的题6（mRNA疫苗版）。

### B. mRNA疫苗principles（Whitehead组的Nature Reviews）

**⭐⭐⭐ Pardi, Hogan, Porter, Weissman 2018, Nat Rev Drug Discov**  
"mRNA vaccines — a new era in vaccinology"

虽然年代稍早，但是这个领域的奠基性综述，引用过万。
让你理解mRNA疫苗为什么需要：
- 5' cap analog (m7G, CleanCap)
- 5'/3' UTR的选择（hAg, β-globin）
- Modified nucleotides (pseudouridine Ψ, 1-methylpseudouridine m1Ψ)
- Poly(A) tail长度
- 纯化（去除dsRNA contaminants）

为什么对你重要：你Portfolio里 mRNA vaccine 版本的题，约束都来源于这些。

### C. mRNA疫苗设计原则的最新版（2021，Whitehead组更新版）

**⭐⭐ Hou, Zaks, Langer, Dong 2021, Nat Rev Mater**
"Lipid nanoparticles for mRNA delivery"
（理解LNP的话）

**⭐⭐ Rohner, Cooper, Dhaliwal, Sharma 2022, Bioeng Transl Med**
"Unlocking the promise of mRNA therapeutics"
（理解mRNA作为药物模态）

### D. 全球访问与工程化前沿（最新动态）

**⭐⭐ Expanding global access to mRNA vaccines, 2026, Nat Rev Bioeng**
DOI: 10.1038/s44222-026-00424-8

讨论了 thermostability、self-amplifying RNA (saRNA)、circular RNA (circRNA)、
AI辅助设计。saRNA和circRNA是接下来5年最热的新模态，你Portfolio里可以
专门设计一道circRNA的题（约束完全不同，要考虑剪接位点和环化效率）。

## Layer 2：codon optimization和mRNA设计的算法核心（必读）

### E. LinearDesign（你这套题的"金标准"参考）

**⭐⭐⭐ Zhang et al. 2023, Nature**
"Algorithm for optimized mRNA design improves stability and immunogenicity"
DOI: 10.1038/s41586-023-06127-z
代码: https://github.com/LinearDesignSoftware/LinearDesign

**为什么必读**：这是当前codon optimization领域的SOTA论文。作者把mRNA设计问题映射成computational linguistics里的lattice parsing问题，用动态规划在11分钟内完成Spike蛋白的最优mRNA设计，同时联合优化CAI和结构稳定性。在COVID-19和水痘带状疱疹疫苗实验中比标准codon optimization提升128倍抗体滴度。

关键点：
- 引入参数 λ 平衡 CAI vs. MFE 这个trade-off — 这正是你题2里
  CAI vs. 5'ΔG冲突的"行业标准解法"
- 算法上从NP-hard问题被巧妙转化为多项式时间可解
- 强烈建议跑一下它的开源代码，把它当作你 problem 2 的"high-end baseline"
  （你的SA solver是中级baseline）

### F. 工具对比综述（最适合做"行业现状"理解）

**⭐⭐⭐ Demissie et al. 2025, J Microbiol Biotechnol**
"Comparative Analysis of Codon Optimization Tools: Advancing toward a 
Multi-Criteria Framework for Synthetic Gene Design"
DOI: 10.4014/jmb.2411.11066

系统比较了JCat、OPTIMIZER、ATGme、GeneOptimizer、TISIGNER、IDT等工具在E. coli、酿酒酵母、CHO三种宿主下的表现。

为什么必读：你Portfolio设计多宿主题目时，这篇是约束选择的依据。
在E. coli里高GC增强mRNA稳定性，但酿酒酵母里A/T富集的密码子才能减少二级结构 —— 这种宿主特异的trade-off是出好题的关键。

### G. Codon harmonization的对比

**⭐⭐ Willems et al. 2023, Microb Cell Fact**
"An exploratory in silico comparison of open-source codon harmonization tools"
DOI: 10.1186/s12934-023-02230-y

Harmonization 和 optimization 不一样：optimization 追求最大CAI，
harmonization 追求保留**原宿主的翻译节奏**（包括有意保留slow codons）。
对你题8（膜蛋白，需要跨膜区慢codon）极其重要。

### H. RNN-based codon optimization（一个用ML替代规则的例子）

**⭐ Fu et al. 2022, ICOR (bioRxiv 2021)**
"ICOR: Improving codon optimization with recurrent neural networks"

为什么了解：这类工作把codon optimization重新formulate成sequence generation。
对你来说这告诉你"模型可以从训练数据中学到密码子pattern"——意味着
你出题要避免那些容易被pattern matching解决的简单约束。

## Layer 3：mRNA二级结构计算工具（你的validator核心依赖）

### I. ViennaRNA Package（业界事实标准）

**⭐⭐⭐ Lorenz et al. 2011, Algorithms for Molecular Biology**
"ViennaRNA Package 2.0"
PMC: 3319429
最新工具包: https://github.com/ViennaRNA/ViennaRNA

基于Turner 2004能量参数的动态规划，提供MFE、partition function、suboptimal folding等。

为什么重要：
- 你的题用的seqfold是pure Python实现，速度慢且精度有限
- 出版级评估必须用RNAfold (ViennaRNA的命令行工具)
- 升级你的validator只需要把seqfold调用替换成`subprocess.run(['RNAfold'])`
- ViennaRNA有Python binding：`pip install ViennaRNA`，可直接`import RNA`

### J. ViennaRNA对修饰碱基的支持（mRNA疫苗题的关键）

**⭐⭐ Lorenz et al. 2023, Bioinformatics**  
"Modified RNAs and predictions with the ViennaRNA Package"
DOI: 10.1093/bioinformatics/btad696

通过soft/hard constraints支持修饰碱基（如伪尿苷Ψ）的结构预测，不需要完整重新参数化能量表。

为什么对你重要：mRNA疫苗用1-methylpseudouridine (m1Ψ) 替换所有U，
这会改变二级结构稳定性。你的Portfolio mRNA vaccine题如果要做严谨，
必须用这个feature重新算ΔG。

### K. SHAPE实验数据整合（顺手了解，难度题用得上）

**⭐ Lorenz et al. 2016, "SHAPE directed RNA folding"**

为什么了解：当你想出"用真实SHAPE数据校正预测"的高级题（题9级别），
soft constraints这个机制让你能把实验数据塞进MFE计算里。

## Layer 4：RNA结构预测的深度学习前沿（题目可以借鉴的"难度天花板"）

### L. RhoFold+ （RNA 3D结构预测的SOTA之一）

**⭐⭐ Shen et al. 2024, Nat Methods**
"Accurate RNA 3D structure prediction using a language model-based deep learning approach"
DOI: 10.1038/s41592-024-02487-0

用RNA语言模型RNA-FM预训练（2300万条unannotated序列），在RNA-Puzzles和CASP15上超过人类专家组。

### M. RNA结构预测deep learning方法系统对比

**⭐⭐ 2024 bioRxiv preprint**  
"A Comparative Review of Deep Learning Methods for RNA Tertiary Structure Prediction"
DOI: 10.1101/2024.11.27.625779

系统比较DRfold、DeepFoldRNA、RhoFold、RoseTTAFoldNA、trRosettaRNA、AlphaFold 3六个模型。读这篇能让你理解2024-2025年RNA结构预测的实际状态——比你想的差，
意味着你出"用AlphaFold3预测RNA结构"类型的题，难度天然高。

### N. PLOS Comp Bio的系统benchmark

**⭐ Schneider et al. 2024, PLOS Comput Biol**
"Systematic benchmarking of deep-learning methods for tertiary RNA structure prediction"
DOI: 10.1371/journal.pcbi.1012715

在5Å cutoff下，DeepFoldRNA/DRFold/trRosettaRNA达到约50%正确率，RoseTTAFoldNA 37%，RhoFold 40%。非ML方法只能预测对不到5%。这个数据告诉你：RNA结构相关的题目，
deep learning模型整体还达不到生产级别——是出题的甜区。

## Layer 5：基因组级别的生成模型（最前沿，影响你Portfolio定位）

### O. Evo 2（Arc Institute的DNA基础模型）

**⭐⭐⭐ Brixi et al. 2026, Nature**
"Genome modelling and design across all domains of life with Evo 2"
DOI: 10.1038/s41586-026-10176-5
代码: https://github.com/arcinstitute/evo2
模型: 7B 和 40B 参数，1M context window，9.3 trillion bp训练数据

Evo 2 在9 trillion DNA碱基对上训练，覆盖所有生命领域。通过beam search能生成带有用户指定染色质可及性pattern的合成DNA。

为什么对你**至关重要**：
- 这是基因组AI的"GPT时刻"——你Mindrift的雇主大概率在做类似规模的模型
- 用Evo 2当对手测试你的题，比测GPT/Claude更能体现专业deepth
- 你的portfolio里可以专门留一道"压测Evo 2 vs 通用LLM"的对比题

### P. Evo 1（前作，理解技术演进）

**⭐⭐ Nguyen et al. 2024, Science**  
"Sequence modeling and design from molecular to genome scale with Evo"
DOI: 10.1126/science.ado9336

7B参数，在270万原核和噬菌体基因组上训练，能zero-shot预测DNA/RNA/蛋白质功能，并设计functional CRISPR-Cas分子复合物和转座系统。

了解这个的演进路径，对理解为什么Evo 2这么强很有帮助。

### Q. Evo 1.5 with semantic gene design

**⭐ Merchant et al. 2025, Nature**
"Semantic design of functional de novo genes from a genomic language model"
DOI: 10.1038/s41586-025-09749-7

延展阅读：基因组语言模型已经能de novo设计functional gene。这是你
"出题给AI"职业未来5年的方向。

### 开源工具（你做portfolio直接能用）

```bash
# 必装
pip install biopython          # 序列操作基础
pip install ViennaRNA          # RNA二级结构，业界标准（注意Linux易装）
pip install dnachisel          # 多约束序列设计框架，最值得用
pip install python-codon-tables  # 各种宿主的codon表
pip install seqfold            # 纯Python RNA folding，免编译，但精度有限

# 高级
pip install rna-tools          # Stanford的RNA Puzzles相关
pip install forgi              # RNA结构操作

# 评估frontier model用
git clone https://github.com/arcinstitute/evo2  # Evo 2 inference
git clone https://github.com/LinearDesignSoftware/LinearDesign
```

**强烈推荐 DNAChisel**（你Portfolio重构时直接用）：
- 提供 `Specification` 抽象，可以声明式描述各种约束
- 内置：AvoidPattern, EnforceGCContent, AvoidHairpins, 
  CodonOptimize, EnforceTranslation 等30+常用约束
- 它的算法（local search + constraint propagation）比你的SA更工业级
- 用它重构validator和solver，代码量会少60%
- 文档: https://edinburgh-genome-foundry.github.io/DnaChisel/

### Workflow 参考（业界mRNA管线长什么样）

```
设计输入：目标蛋白质氨基酸序列
    ↓
[Step 1] 选择宿主codon表 → CHO/E.coli/Yeast/...
    ↓
[Step 2] 联合优化 CAI + MFE （用 LinearDesign 或 DNAChisel）
    ↓
[Step 3] 硬约束检查 → 限制酶位点、剪接位点、homopolymer、CpG岛
    ↓
[Step 4] (mRNA only) U-depletion 替换 → 优先用 m1Ψ-friendly context
    ↓
[Step 5] 加 5'UTR (hAg/β-globin) + Kozak + 3'UTR
    ↓
[Step 6] 模拟二级结构 → ViennaRNA RNAfold 整条 + 5'端 RNAplfold
    ↓
[Step 7] (mRNA only) 加 5' cap + poly(A) tail
    ↓
[Step 8] 合成验证 → IDT/Twist/GenScript 化学合成 → in vitro transcription
    ↓
[Step 9] 体外/体内表达验证 → Western, FACS, mass spec
```

你在portfolio里出"工业级"题时，可以按这个pipeline的不同步骤为题目设场景。

## 阅读路线建议（按你的背景）

你已经有bioinformatics + Python基础，但mRNA特定知识需要补。建议：

**第1-2天**：
- 通读 Jin 2024 综述（A）— 建立坐标系
- 浏览 Pardi 2018（B）— 了解为什么mRNA疫苗这样设计

- 精读 LinearDesign（E）+ 跑通它的代码
- 读 Demissie 2025（F）— 知道行业工具的全貌

**第5天**：
- 装 ViennaRNA + DNAChisel + LinearDesign
- 用LinearDesign跑你portfolio中的几条蛋白，把结果加入baseline

**第6-7天**：
- 读 Evo/Evo 2 论文（O, P）—— 不需要训练，但需要知道这个范式

**之后按需精读**：
- ViennaRNA文档 + Lorenz 2023（J）— 当你升级validator到出版级
- RhoFold/AlphaFold 3 RNA（L, M）— 当你想出RNA结构相关的难题
