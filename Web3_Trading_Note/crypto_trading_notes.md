## 二、常见短线交易策略

### 1. 日内交易（Day Trading）
- 当天开仓、当天平仓，不持仓过夜
- 需要高度专注，适合有大量盯盘时间的人

### 2. 波段交易（Swing Trading）⭐ 推荐新手
- 持仓数天到数周，捕捉中短期趋势
- **对时间要求较低，适合利用空闲时间操作**

### 3. 区间交易（Range Trading）
- 在支撑位买入、阻力位卖出
- 适合震荡行情，逻辑直观

### 4. 突破交易（Breakout Trading）
- 价格突破关键位置时入场
- 需配合成交量确认

### 5. 剥头皮（Scalping）
- 极短时间内频繁交易，赚取微小价差
- 要求极高的专注度和执行速度，**不推荐新手**

## 四、核心风控原则

- **单笔风险控制**：每笔交易风险不超过总资金的 1%–2%
- **只用闲置资金**：亏损后不影响日常生活的资金才能入场
- **止损先行**：入场前就设好止损位，严格执行，不靠感觉
- **避免过度杠杆**：杠杆会成倍放大亏损，新手尽量不用
- **从主流币入手**：BTC、ETH 流动性好，价格相对可预测

## 五、实践建议

1. **先学理论**：通读上方入门资源，理解 K 线、均线、支撑/阻力位等基本概念
2. **用 TradingView 练图**：免费图表工具，边看边画，建立盘感
3. **模拟盘实战**：Binance、OKX 等交易所均提供模拟账户，零成本练手
4. **小仓位真实交易**：模拟盘稳定盈利后，用极小仓位感受真实市场情绪
5. **复盘记录**：每笔交易都记录入场理由和结果，持续改进

## 六、适合空闲时间的路径

> 短线（日内/Scalping）需要长时间盯盘，**波段交易更适合利用碎片时间投资**。

推荐学习顺序：
```
区块链基础 → K线基础 → 支撑/阻力位 → 波段交易策略 → 模拟盘练习 → 小仓位实战
```
